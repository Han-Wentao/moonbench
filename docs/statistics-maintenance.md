# 统计边界维护记录

本次基于 `a307df8`（0.3.0）维护现有统计实现，不改公开 API 或发布版本。

## 问题与修复

`SampleStats::from_samples` 会复制、排序采样，然后计算均值、样本标准差以及中位数、p90、p95。`SampleSeries::median/percentile` 复用相同的私有排序统计函数。因此修复这些函数可以同时覆盖报告摘要和趋势分析，不需要引入第二套统计口径。

1. **百分位整数溢出**：原式 `(count * percentile + 99) / 100 - 1` 在参数钳制前执行 Int 乘法。三个样本 `[1,2,3]` 和 `Int::MAX` 百分位实际返回 1，而约定的上界钳制应返回 3。现在先处理 p≤0、p≥100，再将乘法拆为商和余数。对 1≤p≤99，余数乘积不超过 9801，最终 rank 不超过 count，避免中间 Int 溢出。空序列仍返回 0。
2. **中位数浮点溢出**：`[1e308,1e308]` 的旧结果为 Infinity。现在对同号有限数使用 `a+(b-a)/2`，异号数使用 `(a+b)/2`，保留无穷端点传播行为。相等的最小次正规数不提前折半，避免下溢为零。

此次没有改变排序算法，复杂度仍为 O(n log n)，没有声称运行速度提升。也没有修复 `SampleStats` 均值和方差在极端数值上的全部溢出问题；NaN 输入策略仍沿用现状，需要另行设计。

## 对照与量化验收

| 项目 | 修改前 | 修改后 |
|---|---|---|
| 原有测试 | 59/59 | 原 59 项保持通过 |
| 新增回归 | 两个已执行的复现测试失败 | 5 项新增测试通过，共 64 项 |
| 百分位区间覆盖 | 仅少量示例 | n=1..204、p=1..99，共 20,196 个精确结果比较 |
| 独立统计对照 | 无本次对照 | 64 组确定性输入、每组 5 个指标，共 320 次比较 |
| 极端中位数 | 1e308 等值对返回 Infinity | 返回有限的 1e308；正负混合、次正规数、无穷端点有回归测试 |

独立对照采用 Python 标准库 `statistics.mean/median/stdev`，不是 MoonBench 自己生成期望结果。p90/p95 使用任意精度整数实现 nearest-rank 定义，**不**与 Python 默认的插值分位数混为一谈。种子固定为 20260914，长度 1..64，输入为有限有符号的八分之一整数；比较容差为 `max(1e-9, abs(expected)*1e-12)`。这是明确范围的正确性对照，不是全浮点域保证，也不是与其他 benchmark 框架的速度排名。

Python 标准库参考：https://docs.python.org/3/library/statistics.html
